# Запоминалка: русский язык, ЕГЭ

Сайт: https://ggcreat0r.github.io/EGE.RU/ (GitHub Pages).

Второй адрес: https://ege-ru.egehelp.workers.dev (Cloudflare Workers; из России без VPN может не открываться).

Оба адреса обновляются сами после каждого push в `main`. Прогресс у каждого адреса свой.

Тренажёр в браузере с тремя вкладками:

- **Ударения** — 230 слов и форм, фильтр по частям речи. Нужно нажать на ударную гласную.
- **Пре- и при-** — 61 слово. Нужно выбрать «е» или «и».
- **Словарные** — 314 слов с непроверяемой гласной. Буквы вставляются кнопками; в усложнённом режиме на кнопках все гласные.

Работает с телефона, ставится на главный экран, после первого открытия работает без интернета. Прогресс хранится в браузере.

## Установка на телефон

Android (Chrome): ⋮ → «Установить приложение». iPhone (Safari): «Поделиться» → «На экран Домой».

Сайт публикуется через Cloudflare: проект `ege-ru`, настройки в `wrangler.jsonc`. Папки `tools/`, `data/` и служебные файлы на сайт не попадают (`.assetsignore`).

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html`, `sw.js`, `manifest.json`, `icon-*.png` | готовый сайт |
| `data/words.json` | все слова: ударения, пре-/при-, словарные |
| `tools/template.html` | страница: вёрстка, стили и логика |
| `tools/build.js` | сборка сайта из шаблона и слов |
| `tools/extract.py`, `tools/make_words.py` | извлечение слов из исходных PDF |

## Как поменять слова или оформление

```
cd tools && npm install && cd ..
# правим data/words.json или tools/template.html
node tools/build.js .
```

После этого закоммитить и запушить изменения — Cloudflare обновит сайт сам. Формат `data/words.json`:

- `udar`: `w` — слово, `s` — номер ударной буквы (с нуля), `p` — часть речи, `c` — пометка под словом, `x` и `r` — пояснение после ответа;
- `prepri`: `w` — слово, `g` — номер буквы приставки;
- `slov`: `w` — слово, `g` — номера пропущенных букв, `o` — пара букв на кнопках для каждого пропуска, `d` — однокоренные слова, `c` — пометка.

Буква «ё» во всех словах заменена на «е».
